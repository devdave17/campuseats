# CampusEats
CampusEats is a campus food-ordering system where students can browse restaurants, view menus, order food, make payments, and track deliveries.

## Assignment Tasks

### 1. HTTP Requests

Used `curl -i` to send five requests to a public JSON API.

The `http-log.md` file contains:

* Five request/response pairs
* HTTP status codes
* Content-Type
* Explanation of each response
* One deliberate `404 Not Found` request

### 2. Network Analysis

Used browser **DevTools → Network** with **Disable cache** enabled.

The `network-analysis.md` file contains:

* Number of requests
* Total page size
* Slowest resource
* Any `3xx` or `4xx` responses

### 3. CampusEats Setup

The project is maintained in a Git repository named **campuseats**.

Work is committed step-by-step so the repository has a clear commit history.
